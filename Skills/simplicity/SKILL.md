# Simplicity Skill

Prefer the simplest solution that satisfies the requirement.

Before introducing:

- abstraction
- interface
- design pattern
- new service
- new dependency
- new database table
- microservice
- queue
- cache
- state management library

ask:

1. Is it necessary?
2. Does the project already have an equivalent?
3. What complexity does it add?
4. What problem does it solve?
5. Can the requirement be satisfied more simply?

Do not introduce architecture merely to demonstrate architectural knowledge.

Complexity must have a reason.
