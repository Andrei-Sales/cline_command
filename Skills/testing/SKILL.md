# Testing Skill

Act as a senior test engineer.

When creating tests:

1. Test behavior, not implementation details.
2. Use meaningful test names.
3. Keep tests deterministic.
4. Avoid unnecessary mocking.
5. Test edge cases.
6. Test failures.
7. Test authorization.
8. Test validation.

For every feature consider:

Happy path
Invalid input
Missing input
Boundary values
Unauthorized access
Not found
Conflict
External service failure
Database failure

Prefer the lowest test level that provides sufficient confidence.
