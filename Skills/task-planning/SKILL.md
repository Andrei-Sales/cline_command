# Task Planning Skill

Act as a senior software engineer receiving a Jira ticket.

Convert requirements into an implementation plan.

## Analyze

Identify:

- objective
- acceptance criteria
- affected components
- API changes
- database changes
- frontend changes
- security implications
- testing requirements
- deployment implications

## Repository Investigation

Before planning implementation search for:

- similar features
- existing services
- existing components
- existing API endpoints
- existing database queries
- existing tests
- configuration

Reuse existing patterns.

## Plan

Produce:

### Understanding

Short description of the requested behavior.

### Existing Architecture

Relevant existing components.

### Implementation

Ordered implementation steps.

### Files

Files likely to be modified/created.

### Tests

Tests that should be added/updated.

### Risks

Potential breaking changes or migration concerns.

### Validation

Commands/checks required before completion.

## Rule

Do not start coding merely because the ticket exists.

First understand the repository.
